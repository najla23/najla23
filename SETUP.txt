NAJLA HOSSEINI — PHYSICS × ART

The complete README is ready to use. All original prose, publication entries,
and DOI links have been preserved. The graphics directory is now named nh.

INSTALL
1. Open the public repository https://github.com/najla23/najla23
   Create a public repository named najla23 if it does not exist.
2. Upload README.md to the root, alongside the nh folder from this package:
   README.md
   nh/physics-art.svg
   nh/divider.svg
3. Commit. Your profile is https://github.com/najla23

Keep the filenames and letter case exactly as supplied.
The earlier assets folder is no longer referenced by this README.
If using GitHub's upload interface, drag the nh folder into the repository root.

The artwork combines harmonic curves, wave traces, and painterly gestures.
It is a self-contained SVG with slow light-trace animations, no JavaScript,
and a reduced-motion treatment. The preview PNG is a still image.

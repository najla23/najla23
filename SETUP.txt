GAME
Drag atoms using a mouse or touch. Adjust molecular motion and bond firmness.
Try water, carbon dioxide, or a flexible bead chain. Toggle trails, shake,
pause, reset, or use keyboard controls shown below the canvas.
In Tiny challenge, guide the gold-ringed atom into the target and release it.
Its whole molecule must remain calm for two seconds to collect the target.
The challenge lowers the motion setting to make settling practical.
Reduced-motion users start with the simulation paused and trails off.

This is an illustrative 2D toy using spring bonds, damping, soft collisions,
and random kicks. Controls, masses, lengths, and times use arbitrary units.
It does not implement a validated molecular force field or chemical reactivity.
There are no external game dependencies, account requirements, or API keys.
No network requests are made by the game unless the profile link is clicked.
